# Current Projects:
HashBrownie : HashBrownie is a fast command-line tool that identifies cryptographic hash algorithms by analyzing their structure. It examines prefixes, length, and character sets to guess the hash type with confidence levels. Perfect for CTFs, penetration testing, and breach analysis - it never cracks hashes, only identifies them. It detects MD5, SHA variants, bcrypt, Argon2, NTLM, MySQL5, and many more formats. 

Encoder:Encoder is a defensive security-analysis and data-processing CLI tool that supports Base64, Base32, Hexadecimal, and URL encoding/decoding. It features intelligent automatic format detection with confidence scoring, making it perfect for analyzing encoded data in CTFs, penetration testing, log analysis, and security research.
